# KalaConnect

**Discover. Create. Connect. Sell.**

KalaConnect is an India-focused social commerce platform connecting independent artists, handmade craft creators, interior designers and buyers.

## Vision

Build a digital ecosystem where creators can showcase their work, build their audience, receive custom orders and sell their creations.

## Technology Stack

### Frontend
- React
- TypeScript
- Vite

### Backend
- ASP.NET Core 10 Web API
- C#
- Clean Architecture
- Entity Framework Core

### Database
- Microsoft SQL Server

### Development Practices
- Git and GitHub
- Agile Scrum
- Feature-based development
- Pull Request reviews

## Core Features

- User authentication and profiles
- Artist portfolios
- Social feed and following
- Likes and comments
- Product marketplace
- Custom craft requests
- Direct messaging
- Creator ratings and reputation
- Interior designer collaboration

## Contribution Workflow

All feature development must follow:
1. Create or select a development ticket.
2. Create a feature branch.
3. Implement and test the changes.
4. Raise a Pull Request.
5. Complete code review.
6. Merge and close the ticket.
